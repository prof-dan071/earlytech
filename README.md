# Springdale High School Website

This is the official website for Springdale High School.

## Getting Started

To get started, you will need to have Node.js and npm installed on your machine.

1. Clone the repository: `git clone https://github.com/your-username/springdale-high.git`
2. Install the dependencies: `npm install`
3. Run the development server: `npm start`

## Updating the Website

The website is built with HTML, CSS, and JavaScript. The files are located in the following directories:

- `css/`: Contains the CSS files
- `js/`: Contains the JavaScript files
- `downloads/`: Contains the downloadable files
- `dist/`: Contains the minified CSS and JavaScript files

To update the website, you will need to edit the files in the `css/` and `js/` directories. Once you have made your changes, you will need to run the following command to minify the files:

```
npx gulp
```

This will create new minified files in the `dist/` directory.
